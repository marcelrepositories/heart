# Putaway

Make a mess. Then put it away.

A single page about tidying. Thirty-six tiles sit on a board, one home each. Drag them anywhere, or press Scatter for a seeded mess that the link reproduces, then drag them home one at a time or press Tidy and watch all thirty-six go back in sorted order.

Press Play for Keep it tidy, a run against the board: it knocks tiles loose faster and faster, and your score is how long you keep up.

Three files, no build step: open `index.html`.

GitHub Pages serves the repository root from the default branch; `.nojekyll` keeps every file as it is.
